08 / DIAGNOSTICS & UPDATES

Проверка приложения

GlyphForge самостоятельно проверит безопасные функции и подготовит отчёт, который можно отправить разработчику. Личные сообщения, музыка и контакты в отчёт не попадают.

САМОДИАГНОСТИКАНЕ ЗАПУЩЕНА

Полная проверка выполняет синтетические тесты форматов, правил и звука, проверяет HTTPS, передачу кадров SDK и тестовое уведомление. Может прозвучать короткий тихий тестовый тон 440 Гц. Она не изменяет твою библиотеку и не читает личные сообщения. На матрицу может кратковременно выводиться тестовая точка. Выдай только необходимые разрешения, затем повтори проверку.

Если Android пишет «Доступ для приложения запрещён», открой «О приложении (Android)» → меню ⋮ → «Разрешить ограниченные настройки», если пункт доступен. Затем вернись к доступу к уведомлениям. Это разрешение позволяет читать уведомления; выдавай его только доверенной версии.

Для полного отчёта нажми «Проверить всё».

Проверка ещё не выполнялась
ОБНОВЛЕНИЯGITHUB RELEASES

При открытии приложения выполняется проверка наличия новых опубликованных версий. При наличии релиза открывается официальная страница GitHub во внешнем браузере. GlyphForge не устанавливает APK и не запрашивает разрешение установки приложений. Android проверяет подпись при обновлении.

Версия 0.5.0 · проверка обновлений ещё не выполнялась.

Для обновления уже установленной версии требуется одинаковая подпись APK. Разработчик должен публиковать релизные сборки с постоянным защищённым ключом. Тестовые debug APK, подписанные разными ключами, могут потребовать переустановки.
