# GlyphForge 0.3 — единая студия Glyph Matrix для Nothing Phone (4a) Pro

**Статус: исходный Android-проект; сборка APK и вывод на телефон не проверены.** Это не APK. Браузерные функции редактора проверены автоматическими тестами Chromium. Для светодиодов требуется официальный Glyph Matrix SDK 2.0, Android Studio/CI и реальный Phone (4a) Pro.

## Возможности в одном приложении

- Рисование по сетке **13×13, 137 реальных точек**, яркость 0–255; покадровый аниматор (длительности, предпросмотр).
- Импорт картинок, GIF, видео с конвертацией в светодиоды; для GIF с нарисованной светодиодной сеткой — **специальный режим 13×13**, который считывает центры исходных пикселей без искажения.
- Импорт **Glyph Museum JSON v4 (Phone 4a Pro, 137 элементов на кадр)** с переносом `meta.author`, `postId` и `meta.url`; импорт v1 (Phone 3, 489 элементов) с преобразованием в 13×13. Экспорт JSON v4, `.gforge`, PNG/GIF.
- Библиотека проектов без аккаунта и платных ограничений. Фактические ограничения — память устройства, WebView и ограничение сохранения 64 МБ на один JSON-снимок; большие коллекции можно экспортировать и разделить на несколько файлов.
- В комплекте **Running Kitten** из обоих присланных GIF: 7 кадров по 90 мс. Исходники доступны в `samples/`.
- Встроенный просмотр Glyph Museum и Nothing Playground (в отдельном WebView без привилегированного моста). Можно **вручную загружать** официально доступные файлы и импортировать их. Никакого скрейпинга или копирования закрытой библиотеки.
- Триггеры: уведомление (приложение + ключевое слово), звонок, зарядка вкл./выкл., заряд 100%, низкая батарея, время, экран вкл./выкл., наушники, встряхивание, внешняя команда Tasker/MacroDroid.
- Правила с несколькими **AND-условиями**: дни, временной интервал, заряд, батарея от/до, экран, положение телефона, Wi‑Fi, подключенные наушники, DND. Приоритеты, антиспам-интервал, коэффициент яркости.
- Сценарии — цепочки глифов с паузами, повторами и назначением как цели правила.
- Рингтон: локальный предпросмотр звука совместно с глифом, экспорт аудио в Downloads, кнопка системных настроек звука.

### Системные ограничения

В Android-компонентах события экрана/наушников/встряхивания требуют разрешения Notification Access, поскольку прослушивание запускается в `NotificationListenerService`. Фоновая работа зависит от настроек батареи/ограничений Android; некоторые системные события могут не прийти. Приоритет системной анимации Nothing OS может перекрывать вывод стороннего приложения. Точное совпадение звука и глифа **во время системного входящего звонка не реализовано**. AOD Glyph Toy — экспериментальный. Нет гарантий корректной работы всех функций на живом устройстве до сборки и тестирования.

## Установка Android

1. **Windows:** установи Android Studio, SDK Platform **36** + Build Tools и JDK 17.
2. В папке `GlyphForge` запусти PowerShell: `powershell -ExecutionPolicy Bypass -File .\Build-APK.ps1`.
3. Скрипт скачает **только официальный** Nothing SDK AAR и Gradle 8.13, затем попробует собрать `app\build\outputs\apk\debug\app-debug.apk`. Если SDK или исходный проект потребуют правок, сборка выдаст ошибку, и её нужно исправить по журналу Gradle.
4. Для сборки без локального Android Studio можно загрузить папку проекта в **свой GitHub-репозиторий** и вручную запустить Actions → `Build GlyphForge Android APK`; при успешной сборке файл появляется как Artifacts → `GlyphForge-debug-APK`. Workflow есть в `.github/workflows`.
5. На телефоне установи APK, включи **доступ к уведомлениям** (необязательный для редактора) и разрешение на состояние звонка (только для звонков). Для AOD выбери GlyphForge в настройках Always-on Glyph Toy.

## Как назначить сценарий

1. `Импорт` → выбери фото/GIF/MP4/WEBM; для глифов с сеткой 13×13 выбери «Авто» или «Точная сетка».
2. `Студия` → сохрани в библиотеку.
3. `Сценарии` → добавь нужные работы и повторы, сохрани.
4. `Правила` → выбери событие, нужный сценарий, условия, приоритет и нажми «Добавить правило».
5. Нажми `▶ Тест` у созданного правила для просмотра; физический вывод требует подключенного SDK и телефона.

## Внешний триггер Tasker/MacroDroid

Отправь broadcast Intent с **action** `com.example.glyphforge.RUN` и **package** `com.example.glyphforge`; в строковом extra `key` — уникальный ключ приложения (кнопка `Правила → Ключ для Tasker / MacroDroid`). Дополнительный `ruleId` запускает конкретное сохранённое правило, без него выбирается событие «Внешняя команда». Не публикуй ключ: он предоставляет право удалённого запуска анимаций на телефоне.

## Приватность

Проекты и правила хранятся на телефоне, содержимое уведомлений **не отправляется** в интернет. Браузер сообщества открывается отдельно, без доступа к приватному мосту JavaScript. Разрешения запрашиваются только пользователем. Подключение к сайтам сообщества требует интернет.

## Что реально проверено

`docs/TEST_REPORT.md` содержит результаты теста двух присланных GIF (по 7 кадров, одинаковые включённые LED), прямого JSON-импорта/экспорта Glyph Museum, создания правил и адаптивного интерфейса. Нет Android SDK и реального Phone (4a) Pro в среде — **APK не собран и аппаратное поведение не проверено**.

## Создание собственного репозитория GitHub

По умолчанию репозиторий создаётся **приватным**: пользовательские примеры GIF и экспериментальные исходники не становятся общедоступными.

1. Установи [Git](https://git-scm.com/) и [GitHub CLI](https://cli.github.com/) на Windows.
2. В PowerShell выполни `gh auth login` и войди в свой GitHub.
3. Из распакованной папки GlyphForge выполни `powershell -ExecutionPolicy Bypass -File .\Publish-To-GitHub.ps1`.
4. Скрипт создаст `USERNAME/GlyphForge` и загрузит все файлы в `main`. Если такой репозиторий уже существует, скрипт остановится, не перезаписывая его.

Для публичной публикации при необходимости изменяй видимость отдельно в настройках GitHub.

## Новое в GlyphForge 0.3: музыкальные глифы (Music Reactive)

**Это программная реализация, а не подтверждение работы физической Glyph Matrix:** Android APK и режим аппаратного вывода на Nothing Phone (4a) Pro ещё не собирались и не проверялись в данной среде. Браузерный предпросмотр, поиск и сохранение музыкальных пресетов протестированы отдельно.

### Что добавлено

- Раздел **«Музыка»** с поиском по названиям, категориям и описаниям; 8 встроенных шаблонов: Bass Bars, Night Bass, Bass Pulse, Ripple, Waveform, Strobe Sparks, Orbit, Мой рисунок · Beat.
- Шесть типов реакции: столбцы эквалайзера, кольцо, волна, вспышки, вращение и **анимация из собственной библиотеки**, реагирующая на частоты и удары.
- Редактор музыкального пресета: чувствительность, сглаживание, яркость, оригинальный глиф, имя. Можно сохранять сколько угодно вариантов в пределах памяти телефона.
- Импорт/экспорт одиночных музыкальных профилей `.gforgebeat` (JSON, без исполняемого кода), включение музыкальных профилей в общую резервную копию библиотеки `.gforge`.
- Кнопка **«♪ Beat»** в библиотеке: превращает любое сохранённое изображение, GIF или импортированную чужую работу в музыкальный эффект. Уважай лицензии и авторские права исходных работ.
- Браузерный **Web Audio API** предпросмотр: выбери свой аудиофайл, запусти воспроизведение, и рисунок на экранной матрице начнёт двигаться в реальном времени. Есть отдельный синтетический деморитм без музыки.
- Android-модуль MusicVisualizerService, анализ в памяти без записи на диск:
  - **Режим «Выходной аудиомикс»** использует Android `Visualizer(0)` и спектральный анализ FFT. На отдельных версиях Android или прошивках анализ общего вывода может быть заблокирован.
  - **Режим «Захват воспроизведения»** использует `MediaProjection` + `AudioPlaybackCaptureConfiguration` + `AudioRecord`. Перед запуском обязательно появится системное окно разрешения. Android не позволит записывать аудио приложений, запретивших захват, и содержимое DRM-защищённого воспроизведения.
  - Оба варианта запускаются пользователем из приложения, отображают постоянное уведомление с кнопкой «Стоп», анализируют данные в оперативной памяти и строят кадры 13×13 через Nothing SDK. При паузе или тишине анимация гаснет, служба продолжает ожидать воспроизведение.
- Music Reactive работает как **опциональная foreground-service**. Это позволяет продолжать визуализацию после ухода из интерфейса приложения, пока её не остановит пользователь или система. Автоматически запускать скрытый захват музыки при открытии Spotify/YouTube из фона приложение не пытается — современные версии Android не допускают такой надёжной автоматизации без вмешательства пользователя.

### Как пользоваться

1. На вкладке **«Библиотека»** импортируй чужой GIF/JSON (или создай собственную анимацию).
2. Нажми у него **«♪ Beat»**. Откроется «Музыка» с выбранным рисунком и режимом «Мой глиф».
3. Выбери чувствительность и сглаживание. Проверь результат на своем аудиофайле или на синтетическом демо.
4. Нажми «Сохранить вариант» или «Экспорт .gforgebeat», чтобы поделиться профилем.
5. После установки APK на **Phone (4a) Pro** выбери источник звука и **«Запустить на Glyph Matrix»**. Разреши доступ к аудио; для способа «Захват воспроизведения» подтверди и системный запрос.
6. Запусти музыку в привычном музыкальном приложении. Если первый источник недоступен, останови режим и попробуй второй. Остановить можно в GlyphForge или из постоянного уведомления.

**Технические ограничения:** Nothing OS и другие приложения могут иметь приоритет над `setAppMatrixFrame`; работа через `Visualizer(0)` зависит от поддержки OEM, а `MediaProjection` доступен только после явного согласия и в соответствии с политикой захвата у источника. Не обещается одинаковая работа со Spotify, YouTube Music, Telegram и всеми сторонними плеерами. Нужен эксперимент на реальном Phone (4a) Pro.

### Конфиденциальность

Захваченные аудиосэмплы не сохраняются и не передаются по сети. Сервис преобразует их непосредственно в спектр, громкость и значения светодиодов. Для чтения воспроизведения используется разрешение `RECORD_AUDIO`; во время работы может появляться системный индикатор использования аудио. После команды «Стоп» открытые аудиоресурсы закрываются.
