# GlyphForge 0.4.2 — диагностика v2

«Проверка → Проверить всё» выполняет реальные синтетические циклы форматов и проверки Android, не изменяя проекты. В отчёте отдельные счётчики pass/fail/blocked/untested/pending; pass=null для непроверенных, заблокированных и ожидающих проверок.

Android: версия приложения и ОС, WebView, разрешения, listener, MediaStore write/read/delete, синтетические проверки фильтра уведомлений и развёртки сценария, PCM/FFT-рендеринг, проба Visualizer, тест собственного уведомления без запуска пользовательских правил, проба вызова SDK на свободной матрице, HTTPS трёх известных хостов без cookies. При полной проверке может кратко зажечься центральный LED; вывод не доказывает фактическое свечение. Никакого сбора музыки, сообщений, SSID, токенов, URL посещённых страниц, названий или данных глифов. Журнал ограничен 30 фиксированными кодами событий и временем.

Тест загрузки с авторизацией, видеодекодер на конкретном устройстве, MediaProjection, входящий вызов и физический светодиод обозначаются untested, если нет реального подтверждения. При выдаче разрешений повторить проверку. Отчёт можно сохранить или поделиться; не отправляется автоматически. Сетевой тест проверяет TLS/HTTP, а не содержимое чужого сайта.

Тестовая APK-подпись не гарантирует установку поверх предыдущего debug APK. Сохраните резервную копию библиотеки перед переустановкой.
