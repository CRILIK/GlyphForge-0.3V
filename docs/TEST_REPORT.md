# GlyphForge 0.3 — проверка

## Автотесты (Chromium/Playwright в контейнере)

- Матрица: 13×13 с 137 активными LED — **OK**.
- Начальная библиотека содержит `Сердцебиение`, `Круговая волна` и импортированный `Running Kitten`, у кота 7 кадров — **OK**.
- Glyph Museum JSON `v:4`, `frames[].p` длины 137, `d` и автор/`postId` — импорт, round-trip JSON без потери значений — **OK**.
- Оба реальных GIF (`Running-Kitten.gif` 500×500 и `Running-Kitten (1).gif` 250×250) импортируются с **7 кадрами по 90 мс** — **OK**.
- Между двумя размерами GIF совпали включённые/выключенные точки **на всех семи кадрах** (0 различий при пороге 20); отличия яркости после антиалиасинга — около 0.01–1.64 единицы в среднем на точку — **OK**.
- Правило уведомления Telegram, ключевое слово, батарея от 25%, приоритет 80, cooldown 12 c — сохранение — **OK**.
- JavaScript: нет ошибок в браузере — **OK**.
- Мобильный viewport шириной 390 px: нет горизонтальной прокрутки — **OK**.

## Не проверено

- Сборка Android APK и компиляция Java против Android SDK.
- Связь с реальной Glyph Matrix через AAR/Nothing OS, AOD, системные приоритеты вывода.
- Стабильное получение событий в фоне и ограничения энергосбережения.
- Системная аудио/Glyph-синхронизация входящего вызова — её нет.

## Добавление Music Reactive (версия 0.3, 23.11.2026)

Проверено на встроенном в проект интерфейсе Chrome/Chromium с шириной окна 390 px:

- 137 активных точек матрицы, исходная библиотека и существующий редактор — **OK**.
- Встроенный каталог: **8 музыкальных шаблонов**; поиск по `bass` находит три шаблона — **OK**.
- Создание своего музыкального профиля и сохранение в `state.musicProfiles` — **OK**.
- Экспорт профиля в `.gforgebeat`, импорт файла и повторное сохранение — **OK**.
- Кнопка **«♪ Beat»** для присланного `Running Kitten` назначает режим `art` и сохраняет ссылку на `sample-running-kitten` — **OK**.
- Общий экспорт библиотеки `.gforge` включает новые музыкальные профили — **OK**.
- Синтетическое демо анимирует пиксели, затем корректно останавливается — **OK**.
- Реальный Web Audio предпросмотр на синтезированном 2-секундном WAV: режим `АУДИО LIVE`, движение индикатора спектра и отсутствие JS-ошибок — **OK**.
- Нет горизонтальной прокрутки на телефоне (390 px), мобильный интерфейс сохраняет 7 разделов — **OK**.
- Проверка синтаксиса всех Java-файлов (через `JavacTask.parse` JDK 21, `--release 17`) — **12 файлов, синтаксических ошибок 0**.
- `AndroidManifest.xml` проверен XML-парсером; весь JavaScript проходит `node --check` — **OK**.

**Важно:** Java-парсинг **не является Android-компиляцией**. Gradle, Android SDK и официальный Nothing SDK нужны для проверки типов, ресурсов, APK и исполнения на телефоне. Тестов работы `Visualizer(0)`/`MediaProjection`/потока 137 LED на физическом Phone (4a) Pro пока нет.
