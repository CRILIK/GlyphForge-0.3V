# UB Mode — журнал изменений v0.4

## First Make it Work

1. Прочитан SKILL.md (ub-mode). Написаны регрессионные тесты для самодиагностики, 8 вкладок, safe area, blob-импорта и проверки обновлений.
2. До изменений тесты завершились с пятью ожидаемыми ошибками: отсутствовали раздел диагностики и логика обновлений, CommunityActivity перекрывал status bar и блокировал `blob:`.
3. Изменена структура интерфейса с 8-й вкладкой «Проверка». Добавлен отдельный `diagnostics.js` и Android `DeviceDiagnostics`.
4. CommunityActivity сохраняет HTTPS-файлы как ранее, а для `blob:` использует однократный `JsPromptResult` токен только после пользовательского скачивания. Стороннему WebView не предоставляется `addJavascriptInterface`.
5. Проверка GitHub Releases реализована как асинхронный read-only запрос; установка запускается только пользователем, нет запроса `INSTALL_PACKAGES`.

## Then Make it Right

- Кнопка «Назад» остаётся выше панели жестов/ниже статусбара благодаря `WindowInsets`; высота нажатия >=48dp.
- 8 вкладок помещаются в одну горизонтально прокручиваемую мобильную строку вместо переноса на невидимый ряд.
- Исправлен flaky тест асинхронного импорта JSON: проверка ожидает обновления интерфейса.
- Документация отдельно перечисляет неавтоматизируемые аппаратные проверки.

## Practice

- Запущены `tests_smoke.py` + `test_release_ux.py`.
- Изменения разнесены по отдельным Android/JS-файлам с одной ответственностью.
- Для стабильных обновлений добавлен workflow подписанных GitHub Releases. Ключи не добавляются в репозиторий.
- Статический и браузерный тест не равны испытанию физических 137 светодиодов; это будет отмечено в итоговом отчёте.
